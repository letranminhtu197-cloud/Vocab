Aurestar 16.16.41 — Itsuki Dialogue Persistence Fix
Itsuki's dialogue is shown by default. It is hidden only when you explicitly minimize/hide the companion, and that choice is remembered. Empty message events no longer erase the visible dialogue.

Install: back up current data, extract this ZIP to a separate folder, then open chrome://extensions and use Developer mode → Load unpacked to select the extracted folder. If replacing an existing unpacked extension, keep the original extension directory/ID when replacing files. Back up your data before updating.
