Aurestar 16.16.40 — Workout as one task
All gym-enabled exercise tasks are grouped into one Workout task for daily task counts and the standard Tasks view. The Training page still lists each exercise so the timer can guide each set/interval. The overall Workout task is complete only when all exercises scheduled for that day are completed.
Install: back up current data, extract to a separate folder, then load the extracted extension in chrome://extensions. For an existing extension, keep its original extension directory/ID when replacing files.
